# AVA1 - Desenvolvimento Frontend

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Full Stack, com foco na parte de frontend.

O objetivo do projeto é aplicar conceitos de desenvolvimento web utilizando tecnologias voltadas para construção de interfaces, organização de componentes e estruturação de aplicações modernas.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## Objetivo acadêmico

Este repositório possui finalidade acadêmica e foi criado para atividades práticas da disciplina de Desenvolvimento Full Stack.
